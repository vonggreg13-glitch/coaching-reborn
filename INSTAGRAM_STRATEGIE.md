### 1.2 Patterns de contenu haute-performance (niche coaching féminin)

#### Ce qui PERFORME ✅

| Type de contenu | Pourquoi ça cartonne | Format gagnant |
|---|---|---|
| **Cycle hormonal expliqué simplement** | Sujet tabou + peu d'éducation = fort partage | Carousel ou Reel éducatif |
| **"Je pensais que c'était normal"** | Identification émotionnelle immédiate | Reel POV ou Static quote |
| **Transformation + contexte émotionnel** | L'histoire vend, pas les photos seules | Carousel avant/après narratif |
| **Démystification d'un mythe fitness** | Contre-intuitif = save + partage | Carousel 5-8 slides |
| **"Ce que personne ne te dit sur [X]"** | Curiosité gap = forte rétention | Reel talking head ou Carousel |
| **Check-in dailys / routines matinales** | Aspiration + accessibilité | Reel lifestyle court |
| **Score / résultat chiffré client** | Preuve sociale concrète | Static ou Carousel |
| **Affirmation + contexte pratique** | Enregistrable, repartageable | Static ou Story |

#### Ce qui NE PERFORME PAS ❌

| Type de contenu | Pourquoi ça ne fonctionne pas |
|---|---|
| Posts promotionnels directs ("travaille avec moi") | Reach organique effondré, ressemble à une pub |
| Photos d'entraînement sans narration | Pas de différenciation, noyé dans la masse |
| Captions courtes sans hook | Pas d'arrêt du scroll, pas de save |
| Contenu trop générique ("mange bien, dors bien") | Zéro valeur ajoutée perçue |
| Graphismes surchargés | Lecture difficile sur mobile, pas de stop-scroll |
| Avant/après sans histoire émotionnelle | Impression de vente agressive |

## PARTIE 2 — FRAMEWORK STRATÉGIQUE

### 2.1 Positionnement éditorial

> **"La seule méthode de coaching qui écoute ton corps avant de te donner un programme."**

REBORN se différencie par son approche data + cycle hormonal + suivi quotidien. Le contenu Instagram doit **incarner cette philosophie** plutôt que de vendre un service.

```

│  PILIER 1        │  PILIER 2        │  PILIER 3    │  PILIER 4  │

│  Nutrition       │  limitantes      │  Process     │  Témoig.   │
│  Hormones        │  Identité        │  Vrai toi    │  Chiffres  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 Formule de publication recommandée

| Jour | Format | Pilier | Objectif algorithmique |
|---|---|---|---|
| Lundi | Reel (20-45s) | Éducation | Reach nouveau public |
| Mercredi | Carousel (6-10 slides) | Éducation / Transformation | Saves + partages |
| Vendredi | Reel (15-30s) | Intimité coach | Commentaires + connexion |
| Dimanche | Static ou Carousel court | Preuve sociale | Sauvegardes |
| Stories quotidiennes | Sondage / Quiz / Behind-the-scenes | Tous | Retention + DMs |

**Rythme cible :** 4 posts/semaine + Stories quotidiennes (5-7 Stories/jour)

### 2.4 Anatomie d'un post haute-performance REBORN

```
REEL (structure 30-45 secondes)
├── 0-3s  : Hook visuel + Hook texte (même message, double impact)
├── 3-10s : Problème identifiable (l'audience se reconnaît)
├── 10-25s : Insight / Solution unique REBORN
├── 25-35s : Preuve ou exemple concret
└── 35-45s : CTA doux (save · partage · DM)

CAROUSEL (structure 7-9 slides)
├── Slide 1 : Hook fort (arrêt du scroll)
├── Slide 2 : Problème amplifié
├── Slides 3-7 : Contenu de valeur (liste, étapes, révélations)
├── Slide 8 : Récap / takeaway principal
└── Slide 9 : CTA (save · DM · lien bio)

STATIC
├── Visuel : Palette turquoise-violet, typographie Montserrat
├── Texte max 8 mots (lisible au scroll)
└── Caption : Hook + valeur + CTA (150-300 mots)
```
